# Imagens

Imagens da obra One Piece, de Eiichiro Oda / Shueisha / Toei Animation, usadas na apresentação deste projeto de fãs. A inclusão neste repositório não transfere direitos sobre a obra.

Arquivos de origem disponíveis em:
- https://github.com/Punith-KK/One_Piece_Cosmos/tree/main/DraggableMenu-master/img (personagens)
- https://github.com/Punith-KK/One_Piece_Cosmos/tree/main/GridRevealEffects-master/img (frutas)
- https://github.com/Punith-KK/One_Piece_Cosmos/tree/main/OnePiece_Website/resources (cenários)

Os arquivos foram reduzidos e convertidos para WebP para carregamento local.
